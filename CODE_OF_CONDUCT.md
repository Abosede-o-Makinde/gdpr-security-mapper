# Code of Conduct

## Our pledge

Everyone participating in this project should be able to do so without harassment, regardless of background or experience.

## Expected behaviour

- Be respectful and constructive
- Accept feedback gracefully
- Focus on what's best for the project and its users

## Unacceptable behaviour

- Harassment, insults, or personal attacks
- Unwelcome sexual attention or inappropriate language
- Publishing private information without consent
- Anything that would be out of line in a professional setting

## Scope

Applies in GitHub issues, pull requests, discussions, and anywhere else this project is represented.
